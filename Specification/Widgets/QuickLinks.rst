===========
Quick Links
===========

:Setting: :confval:`enableWidgetQuickLinks`
:Size: small
:Refresh button: no

Shows the project links of :confval:`customQuickLinks` and shortcuts to
common backend modules (Layout, Records, Media, Sites, Scheduler, Extensions,
Settings). Backend shortcuts are only shown if the module is installed and
accessible for the current backend user.
