===========
Site Health
===========

:Setting: :confval:`enableWidgetSiteHealth`
:Size: large
:Refresh button: yes

Displays live metrics of the default (live) workspace:

- published and hidden pages
- files in FAL (without missing files)
- broken links found by EXT:linkvalidator
- active tasks of EXT:scheduler

Metrics of not installed system extensions are shown as ``–``.
